# E-Commerce Sales & Orders Analytics
## Project Overview
This project focuses on analyzing e-commerce sales and order data using Power BI. The objective was to transform raw data into meaningful business insights through data cleaning, DAX calculations, interactive dashboards, and KPI analysis.

## Tools & Skills
- Power BI
- DAX
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization
= KPI Analysis
- Business Intelligence

## Analysis Performed
- Cleaned and transformed e-commerce data to improve reporting accuracy and consistency.
- Developed an interactive Power BI dashboard to monitor sales, orders, and key business KPIs.
- Created DAX measures for performance analysis and KPI tracking.
- Analyzed sales and order trends to identify business performance patterns.
- Used interactive visualizations to support business performance monitoring.

## Key Areas of Analysis
### 1. Sales Analysis
Analyzed sales performance and trends to understand changes in business performance over time.

### 2. Order Analysis
Analyzed order volumes and trends to identify patterns in customer purchasing activity.

### 3. KPI Analysis
Created DAX measures to calculate and track important business performance indicators.

### 4. Dashboard
Developed an interactive Power BI dashboard to present sales, orders, and KPIs in an easy-to-understand format.
